Deploy DarkWatch Remote Agent

Stream telemetry from any Windows, Linux, or macOS endpoint

1

Copy the Agent Folder

Copy the agent/ folder from this DarkWatch repository onto the target host machine.

2

Configure Server URL & Agent Token

Open agent/agent_config.json on the client machine. Update server_url to point to this server's LAN or Public IP:

{
  "server_url": "http://YOUR_SERVER_IP:5000/api/telemetry/ingest",
  "agent_token": "DarkWatch-Telemetry-Key-2026",
  "poll_interval_seconds": 10
}
3

Run the Agent Daemon

Windows (1-Click): Double click run_agent.bat or run PowerShell:

cd agent
python telemetry_agent.py

Linux / macOS: Run:

pip install requests psutil
python3 agent/telemetry_agent.py

The agent will automatically generate a persistent UUID, start sampling CPU/RAM/Disk and TCP sockets, and stream telemetry back here every 10 seconds.
